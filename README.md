# Inventory Management System (IMS) for Fish Business

A comprehensive inventory management system specifically designed for businesses that sell fish, featuring specialized cold storage container management for different fish types and varieties.

## About

This IMS is tailored for fish businesses that require precise tracking of their inventory across multiple cold storage containers. The system is designed to handle the unique challenges of fish retail, including temperature-sensitive storage requirements, varying fish types, and perishable inventory management.

## Core Features

### Container Management
- **Cold Storage Container Tracking**: Monitor and manage multiple cold storage units with different temperature requirements
- **Container Assignment**: Assign specific fish types to appropriate storage containers
- **Temperature Monitoring**: Track temperature conditions for optimal fish preservation
- **Capacity Management**: Monitor storage capacity and utilization across all containers

### Fish Type Tracking
- **Species Classification**: Organize inventory by fish species, varieties, and grades
- **Batch Tracking**: Track fish batches from supplier to sale with lot numbers and dates
- **Quality Grading**: Manage quality classifications and grading systems
- **Expiry Management**: Monitor freshness and shelf life for optimal turnover

### Inventory Monitoring
- **Real-time Stock Levels**: Live tracking of fish quantities across all containers
- **Automated Alerts**: Low stock, temperature variance, and expiry warnings
- **Movement Tracking**: Track fish transfers between containers and locations
- **Loss Management**: Record and track spoilage, shrinkage, and waste

## Business Management Modules

### Sales and Order Management
- **Point of Sale Integration**: Process customer sales and transactions
- **Order Processing**: Handle customer orders and special requests
- **Pricing Management**: Dynamic pricing based on market conditions and freshness
- **Sales Analytics**: Track sales performance by fish type, time period, and customer

### Supplier and Vendor Management
- **Supplier Profiles**: Maintain detailed supplier information and performance metrics
- **Purchase Order Management**: Create and track purchase orders with suppliers
- **Delivery Scheduling**: Coordinate fish deliveries and receiving schedules
- **Supplier Performance**: Monitor delivery times, quality, and pricing

### Customer Management
- **Customer Database**: Maintain customer profiles and purchase history
- **Loyalty Programs**: Implement customer rewards and loyalty tracking
- **Order History**: Track customer preferences and buying patterns
- **Communication Tools**: Send notifications about fresh arrivals and special offers

### Financial Tracking
- **Revenue Tracking**: Monitor sales revenue by fish type, time period, and location
- **Cost Management**: Track purchasing costs, storage expenses, and operational costs
- **Profit Analysis**: Calculate profit margins by fish type and overall business performance
- **Payment Processing**: Handle various payment methods and transaction records

### Reporting and Analytics
- **Inventory Reports**: Detailed reports on stock levels, turnover rates, and container utilization
- **Sales Analytics**: Comprehensive sales reporting with trend analysis
- **Financial Reports**: Profit and loss statements, cost analysis, and revenue tracking
- **Operational Metrics**: Key performance indicators for business optimization

## Project Status

## Technology Stack

- **Frontend**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **Build System**: Next.js built-in build system

## Development Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
